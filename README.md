# Утга · Монгол хэл ба AI

Монгол үг, хэлц, зүйр үг, ёгтлол, ахуйн утгыг эх сурвалж болон хэрэглээний жишээтэй хайх толь.

## Тайлбар толь — үндсэн хуудас `/`

- Олон мянган бодит эх сурвалжтай үг, холбоо үг, хэлцийн сан. Бодит тоо болон хэлний задаргаа `data/metadata.json`-д байна. Монгол эхийг түрүүлж харуулна.
- Үг, хэллэг, тайлбарын хайлт; зургаан ангилал; хуудаслалт; олон утга; хэрэглээний жишээ; холбоотой үг; эх сурвалжийн холбоос.
- Хайлтад API түлхүүр шаардлагагүй. Өгөгдөл серверийн JSON сангаас уншигдана, хөтөч рүү бүх санг ачаалахгүй.
- AI-аар утга, шууд/далд утга, хэрэглэх нөхцөл, тайлбартай хоёр шинэ жишээ гаргана. Хайлтаар олдсон лавлахыг AI-д өгнө. Ёгтлолд өгүүлбэрийн нөхцөл нэмж болно.
- AI холболт байхгүй үед тохиргоо нээнэ; зохиомол хариу үзүүлэхгүй. Танигдаагүй үгийг заавал мэддэг мэт тайлбарлахгүй байх заавартай ч AI-ийн алдааг бүрэн арилгах баталгаа биш.
- Монгол Викитоль болон Kaikki/English Wiktionary-ийн эх сурвалжийг хадгалсан. Англи тайлбаруудыг тусад нь тэмдэглэнэ. `DATA_SOURCES.md`-д CC BY-SA 4.0 лиценз, шинэчлэх алхмууд бий.
- Эх сан нь бүх монгол үгийг хамрахгүй. Зарим бичлэгт жишээ дутуу; AI-аар дэлгэрүүлэх нь төлбөртэй API холболт шаарддаг. Олон нийтэд нээлттэй редакц, хэрэглэгчийн бүртгэл, төв SQL сан одоогоор байхгүй.

## Судалгааны лаборатори — `/research`

### Лабораторийн боломжууд

- Монгол интерфэйс, гар утас болон компьютерийн дэлгэцэд тохирно.
- Дөрвөн ангилалтай 24 **шинжээчээр баталгаажаагүй эхлэх жишээ**. Шинэ хэллэг нэмэх, засах, JSON импорт/экспорт.
- OpenAI Responses API-ийн бодит хүсэлт. Шууд / нөхцөлтэй / хоёр тусдаа жишээтэй асуулт; 1–3 давталт; хүсэлтүүд санамсаргүй дарааллаар ажиллана.
- Алтан хариулт, эх сурвалж, ангиллыг AI руу дамжуулахгүй. Prompt болон түүний хувилбарыг үр дүн бүрд хадгална.
- Хүний үнэлгээ: утга, нөхцөл/соёлын нийцэл, ойлгомж, тус бүр 0–2; загвар/аргыг нуух; алдааны ангилал.
- Дундаж оноо, туршилт/аргын шүүлт, бүрэн CSV, JSON нөөц болон нөөц нэгтгэх.
- Үр дүн бүрд бодит загварын ID, хугацаа, токен, API response ID, огноо, хүсэлт хадгална.
- API түлхүүр зөвхөн React санах ойд. localStorage, URL, лог, git-д хадгалахгүй. Серверээс зөвхөн OpenAI руу хүсэлт илгээнэ.

## Локал ажиллуулах

Node.js 22+:

```sh
npm ci
npm run dev
```

http://localhost:3000 нээнэ. Тохиргоо → өөрийн OpenAI API түлхүүр → зөвшөөрлийн checkbox → туршилт. API төлбөр OpenAI бүртгэлд тооцогдоно. ChatGPT-ийн захиалга нь API кредит биш.

```sh
npm test
npm run typecheck
npm run build
npm start
```

## GitHub ба Vercel

Шинэ, хоосон repository үүсгээд:

```sh
git init -b main
git add .
git commit -m "Build Mongolian meaning evaluation lab"
git remote add origin https://github.com/YOUR_ACCOUNT/mongol-utga.git
git push -u origin main
```

Vercel → Add New Project → GitHub repository `mongol-utga` → Framework **Next.js** → Deploy. Root directory нь энэ хавтас байна. `main` руу push хийхэд Vercel автоматаар deploy хийнэ.

Өөрийн API түлхүүр оруулах горимд Vercel environment variable шаардлагагүй. Хамтын серверийн түлхүүр хэрэглэх бол Vercel Settings → Environment Variables дээр **хоёуланг** тохируулна:

| Variable | Утга |
|---|---|
| `OPENAI_API_KEY` | OpenAI төслийн API түлхүүр |
| `RESEARCH_PASSWORD` | Урт, санамсаргүй судалгааны нууц үг |
| `OPENAI_MODELS` | Сонголттой, таслалаар тусгаарласан зөвшөөрөгдсөн model ID. Анхны утга `gpt-4.1-mini,gpt-4.1` |

Дараа нь Redeploy. `NEXT_PUBLIC_` нэртэй түлхүүр **бүү** ашигла. Түлхүүр болон нууц үгийг git-д бүү оруул. Хамтын нууц үг эзэмшигчид API зарцуулалт хийж чадна; энэ горимыг зөвхөн итгэмжлэгдсэн судалгааны багт хэрэглэж, OpenAI төслийн зарцуулалтын хязгаарыг тохируул. Энэ хувилбар байгууллагын хэрэглэгч бүрийн эрх, distributed rate limiting агуулаагүй.

## Хадгалалтын хүрээ

Тайлбар толь нь versioned JSON өгөгдлөө серверээс уншина. Судалгааны лаборатори нь нэг судлаачийн хөтөчид ажиллана. Хэллэг, үр дүн, хүний үнэлгээ **localStorage**-д хадгалагдана. Төв өгөгдлийн сан, төхөөрөмж хооронд автомат синк байхгүй. Хариу ирэх бүрд хадгална; хадгалалт дүүрвэл туршилт зогсож JSON нөөц авахыг шаардана. Нууц горим эсвэл site data устгах нь үр дүнг устгаж болно. JSON нөөцөө тогтмол тат.

Нөөц нэгтгэх нь шинэ ID-тай бичлэгүүдийг нэмнэ; хуучин ID-тай бичлэгийг дарж бичихгүй. Нэг хариултад нэг идэвхтэй үнэлгээ хадгална. Олон үнэлэгчийн ажилд тус тусдаа файлуудаар үнэлж, response `id`-аар гадаад шинжилгээнд нэгтгэ.

## Судалгааны хязгаар ба зөв хэрэглээ

Эхлэх өгөгдлийн нөхцөл болон тайлбаруудыг энэ төслийн жишээ болгон зохиосон. Баталгаажсан соёлын стандарт эсвэл шинжлэх ухааны benchmark гэж үзэж болохгүй. Хоёр хэлний шинжээчээр нягтлуулж, эх сурвалжийг шинэчил.

Тестийн санд few-shot-д хэрэглэсэн «Нүүр хийх газаргүй болох», «Мөн ч хурдан юм аа!» жишээг оруулахгүй. Шууд асуултын аргад нөхцөл өгөхгүй тул олон утгатай хэллэгийн ялгааг тайланд тайлбарла. Загваруудын нарийвчлал гэж хүний онооны дунджийг бүү нэрлэ. Давталтууд нэг хэллэгт хамаатай: CSV-ээс хэллэгээр хослуулсан шинжилгээ, итгэлцлийн интервал, алдааны ангилал гарга.

Зөвхөн OpenAI Responses API болон structured output дэмждэг загваруудыг ашиглана. API алдаа, квот, буруу түлхүүр, тасалдлыг ил харуулна. Хуурамч AI хариу эсвэл demo оноо байхгүй. API түлхүүргүй үед хэллэгийн сан, импорт/экспорт, интерфэйс ажиллана; шинэ AI хариу үүсгэхгүй.

## Технологи

Next.js App Router, React, TypeScript, Zod, Lucide, CSS. Сервер route нь зөвхөн `https://api.openai.com/v1/responses` руу холбогдоно; arbitrary endpoint дэмжихгүй. Origin, оролтын хэмжээ, schema, shared model allowlist шалгана. Хүсэлтийн timeout 50 секунд, Vercel maxDuration 60 секунд. API key/request body-г логлохгүй. CSV formula injection-аас хамгаалсан.
